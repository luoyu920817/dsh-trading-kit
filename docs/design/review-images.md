# 复盘卡片图片契约

日期：2026-10-07。在既有复盘卡片上增量支持图片，不迁移旧文档，不新增依赖。

## 编辑与展示

初始输入框与历史卡片的行内编辑均支持粘贴截图、选择本地图片；不支持拖拽。
textarea 的光标处插入 `![[files/review-<唯一标识>.png]]`；输入区下方只显示这些已插入图片的
缩略图，正文文本不重复渲染（owner 2026-10-07：输入框已显示原文，整段镜像渲染是噪声；
缩略图筛选与上传筛选同源 `imagePreviewItems`，点击缩略图复用页内原图弹层）。
图片保留在草稿内存，只有保存时随正文提交；未保存的图片不操作 vault（历史卡片编辑取消亦然）。
保存失败保留正文、图片及提交标识，重试不得生成重复卡片或附件。
图片处理期间禁止提交；异步读文件不得把附件写进另一个标的、市场或交易日的草稿。

历史区按正文顺序显示文字和图片缩略图，点击图片在页内查看原图。
普通文本用文本节点呈现，不解析任意 HTML。代码围栏与行内代码中的图片语法不是图片引用。
缺图展示占位并返回告警；不支持的嵌入语法保留为文本。

## 文件与接口

图片位于已定位复盘 Markdown 的同目录 `files/`，即 `DB/review/<YYYYMM>/files/`。
Markdown 只保存相对引用，不存 Base64，不依赖浏览器 Blob URL 或机器绝对路径。
允许 PNG、JPEG、WebP、GIF，服务端检查签名和扩展名；单图上限 10 MiB，
一次提交解码后合计上限 20 MiB，JSON 请求体上限 30 MiB。文件读写和删除不越出该月 `files/`，
拒绝绝对路径、路径穿越及符号链接越界。

现有 `POST /review/api/card` 和 `/review/api/card/update` 可选接收：

```ts
images?: Array<{ relativePath: string; dataBase64: string }>
```

每张上传图片必须被所提交正文实际引用；只携带新插入的图片，已有图片只需保留正文引用。
旧请求不含 `images` 时继续使用原保存机制；旧 Markdown 不自动改写。

新增 `GET /review/api/card/image` 参数为 `code`、`tradeDate`、`relativePath`，
返回图片原始字节及经过验证的 MIME，使用 `no-store` 和 `nosniff`。
认证沿既有读通道；读图不发出站网络请求。

新增 `POST /review/api/card/image/delete` 接收 `{anchor, relativePath}`，
返回 `{status: 'updated', anchor, path, warnings}`。认证沿既有写凭据，Host/Origin 栅栏不得绕过。
不得接收客户端替换正文，须在存储锁内基于最新卡片移除该图片引用。

历史本地读取与 `review_read_daily` 的卡片可选增加：

```ts
images?: Array<{
  relativePath: string
  path: string // 安全解析的绝对路径，供宿主 read_image 使用
  mimeType: string
  available: boolean
}>
```

无图片卡片保持旧字段形状；用户正文、时间、锚点、AI 附注与卡片计数口径保持兼容。

## 写入与删除事务

图片与正文复用已有卡片互斥锁、幂等标识和原子 Markdown 写入。新文件不覆盖既有文件；
同路径同字节可用于重试，同路径不同字节必须拒绝。正文提交失败只回收本次创建的图片。

历史图片删除需要二次点击确认，并提示同时删除原文件，会影响其他笔记对该文件的引用。
先将待删除图片同目录暂存，再原子修改正文；正文失败恢复原图，成功后删除暂存文件。
清理失败明确告警，不声称文件已完全清除。编辑移除图片和删除整张卡片也清理对应原图。
删掉最后一张图片时保留卡片的时间、锚点和元信息，历史界面显示空正文占位。
不扫描和清理整个目录的孤立文件。

## Agent 消费与验收

复盘 skill 在 W3 调用 `review_read_daily` 后，对可用图片显式执行
`read_image({file_path: 图片绝对路径})`，同路径去重；图片内容结合文字进入后续分析。
路径存在不等于模型已阅读。缺图、工具不可用、无视觉模型时记录缺失与告警，继续处理文字。
不增加新的图片工具、附件服务依赖，也不由插件创建 agent 会话。

自动门禁：`pnpm typecheck && pnpm build && pnpm test`；合规脚本自检及既有结构、写入边界检查。
使用真实临时目录覆盖图文保存、仅图片、编辑、幂等、删除、失败回滚、缺图、类型/大小/路径拒绝，
并验证 BOM/EOL、其他卡片及附注保真。不得为测试修改生产 vault。

现场验收：TDX Chromium 81 中粘贴截图、选择文件、刷新、原图查看、删图；
Obsidian 中打开生成文档验证嵌入；支持视觉的 DSH 会话中确认 `read_image` 的实际调用与图像返回。
自动测试不能替代宿主的剪贴板、视觉模型和工具可见性检查。
